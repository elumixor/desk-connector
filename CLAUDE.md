# @desk/connector

The connector protocol and base class, consumed as source via `github:elumixor/desk-connector#v<version>` (never published to npm). `src/index.ts` holds the `Connector` the host sees and the `Host` a connector is handed at runtime; `src/base.ts` is `BaseConnector`, which every connector in `elumixor/desk-connectors` extends; `src/http.ts` the responses routes answer with; `src/card.ts` the cards a connector posts into an agent's chat (`host.cards`, `press`); `src/testing.ts` an in-memory `Host`. Keep it minimal and dependency-free apart from zod: a field belongs here only when a connector actually uses it. A change bumps `version` and gets a `v*` tag, since pai and `desk-connectors` pin the tag. `bun run typecheck`, `bun run lint`.
